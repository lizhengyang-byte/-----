# 土力学快速查阅手册（期末考试 / 考研版）

面向大学生期末考试与考研复习的土力学系统性速查手册。**分章节建立文档，公式完整析出**，考前可用于系统过一遍公式，考场可快速定位某一公式。

---

## 项目结构

| 路径 | 说明 |
|------|------|
| `README.md`（根目录） | 项目总览 README（项目首页） |
| `markdown版本/` | 全部 Markdown 源文档（README、各章、总册） |
| `markdown版本/README.md` | 本说明文件（手册使用说明） |
| `markdown版本/00-全书公式速查总表.md` ~ `08-地基承载力.md` | 各章 Markdown 源文档 |
| `markdown版本/土力学速查手册-总册.md` | 合并总册（封面 + 目录 + 各章全文，不含 README） |
| `PDF导出/` | 各章与总册的 PDF（学术黑白 A4，pandoc + xelatex 构建） |
| `LaTeX版本/` | 每个 Markdown 对应的独立可编译 `.tex` 源文件 |
| `latex_log/` | LaTeX 编译过程文件（`.aux`/`.log`/`.toc` 等，自动生成，无需关注） |
| `.claude/pdf-build/` | 构建管线（版式模板、Lua 过滤器、构建脚本） |

### LaTeX 版本说明

`LaTeX版本/` 中每个 `.tex` 均由对应 Markdown 生成，内嵌本手册版式模板（ctex 中文字体、三线表、页眉页脚），**独立自包含**——直接用 `xelatex` 编译即可得到与 `PDF导出/` 一致版式的 PDF：

```bash
# 在项目根目录执行
xelatex "LaTeX版本/土力学速查手册-总册.tex"
```

- 各章 `.tex` 对应单章 PDF；`土力学速查手册-总册.tex` 已含居中封面与带页码目录。
- 修改 Markdown 后（在项目根目录）重新生成 LaTeX 版本：`bash .claude/pdf-build/build_tex.sh`；一键导出全部 PDF：`bash .claude/pdf-build/build.sh`。

### 快速入手路径

- **考前 2 小时**：直接看「00-全书公式速查总表」。
- **逐章复习**：按目录顺序，每章以「本章导览 → 核心公式（参数/单位/适用说明）→ 公式索引小结」结构展开。
- **某个公式记不清**：用编辑器全文搜索关键词（如"固结度""朗肯"），或在章末「本章公式索引」定位。

### 公式渲染说明

本手册公式使用 **LaTeX 数学语法**，在以下环境可正常显示：

- **Typora**：默认支持，打开即可见。
- **Obsidian**：需开启「设置 → 编辑器 → 数学公式」。
- ** VS Code + Markdown Preview Enhanced**：默认支持。
- **GitHub** 网页预览：默认支持 KaTeX 渲染。

排版约定：行内公式用 `$...$`，独立公式用 `$$...$$`，关键结论用 `\boxed{}` 高亮，多步推导用 `$$\begin{aligned}...\end{aligned}$$`。

不想在编辑器中预览公式时，可直接用 `LaTeX版本/` 中的 `.tex` 文件编译成 PDF（见「项目结构 · LaTeX 版本说明」）。

### 编写维护约定（后续扩充规范）

1. **文件命名**：`NN-章节主题.md`，NN 两位数字保持排序。
2. **公式编号**：不依赖自动编号，正文用「公式 1-1、1-2…」手工编号，首个数字为章号。
3. **公式三段式**：每个公式后必须有「参数说明」「单位」「适用条件/注意」三段，保证可独立阅读理解。
4. **新章节模板**：沿用「本章导览 → 核心公式 → 本章公式索引小结」结构，并在「00-全书公式速查总表」中登记新公式。
