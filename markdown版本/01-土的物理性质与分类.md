# 第一章 土的物理性质与工程分类

> **本章导览**：本章是全部后续章节的计算基础，考试中以**三相比例指标的定义与互相换算**为最高频考点（几乎每年必考），其次是液限/塑限与土的分类判别。计算题常给出任意三个实测指标，要求推出其余指标——建议背熟「换算组」（公式 1-8 至 1-13）。

---

## 1.1 土的三相组成与基本记号

土 = 固相（土粒）+ 液相（水）+ 气相（空气）。按质量、体积分别记为：

| 物理量 | 记号 | | 物理量 | 记号 |
|--------|------|--|--------|------|
| 土粒质量 | $m_s$ | | 土粒体积 | $V_s$ |
| 水质量 | $m_w$ | | 水体积 | $V_w$ |
| 空气质量 | $m_a\approx0$ | | 空气体积 | $V_a$ |
| 土样总质量 | $m=m_s+m_w$ | | 孔隙体积 | $V_v=V_w+V_a$ |
| — | — | | 总体积 | $V=V_s+V_v$ |

实验中直接测得的三个基本指标：**密度 $\rho$、含水率 $\omega$、土粒相对密度 $d_s$**，其余指标均可由它们换算。

---

## 1.2 三相比例指标（九个基本指标定义）

### 公式 1-1　含水率

$$\omega=\frac{m_w}{m_s}\times100\%$$

- **参数说明**：$\omega$ 为含水率（%）——土中水的质量与土粒质量之比；$m_w$、$m_s$ 同上节。
- **单位**：无量纲（常以百分数表达）。
- **注意**：含水率以**干土质量**为分母，切莫写成 $m_w/(m_s+m_w)$。

### 公式 1-2　土的质量密度与重度

$$\rho=\frac{m}{V},\qquad \gamma=\rho g=\frac{mg}{V}$$

- **参数说明**：$\rho$ 为土的质量密度（$\mathrm{g/cm^3}$ 或 $\mathrm{kg/m^3}$）；$\gamma$ 为土的重度（$\mathrm{kN/m^3}$）；$g$ 为重力加速度，取 $10\,\mathrm{m/s^2}$；$m$、$V$ 为总质量与总体积。
- **换算**：$1\,\mathrm{kN/m^3}=1000\,\mathrm{kg/m^3}\times10\,\mathrm{m/s^2}/1000$，即 $\gamma(\mathrm{kN/m^3})=10\rho(\mathrm{g/cm^3})$。
- **注意**：水的重度 $\gamma_w=10\,\mathrm{kN/m^3}$，$\rho_w=1\,\mathrm{g/cm^3}$。

### 公式 1-3　土粒相对密度（土粒比重）

$$d_s=\frac{m_s}{V_s\rho_w}=\frac{m_s}{V_s}\cdot\frac{1}{\rho_w}$$

- **参数说明**：$d_s$ 为土粒相对密度（无量纲），数值上等于土粒密度与 4℃ 纯水密度之比；$\rho_w$ 取 $1\,\mathrm{g/cm^3}$（此时 $d_s=\rho_s/\rho_w$，$\rho_s$ 为土粒密度）。
- **经验值**：砂土 $2.65$，粉土 $2.68$，黏性土 $2.72\sim2.75$。
- **注意**：$d_s$ 与土的密度 $\rho$ 是**完全不同**的概念，前者是土粒自身，后者是三相整体的平均密度。

### 公式 1-4　孔隙比与孔隙率

$$e=\frac{V_v}{V_s},\qquad n=\frac{V_v}{V}\times100\%$$

$$n=\frac{e}{1+e},\qquad e=\frac{n}{1-n}$$

- **参数说明**：$e$ 为孔隙比；$n$ 为孔隙率（%）；$V_v$、$V_s$、$V$ 意义同上。
- **换算**：二者一一对应，考试中常需互转。$e$ 常为小数（砂土 $0.4\sim0.8$，黏性土 $0.6\sim1.2$）。
- **注意**：$e$ 以 $V_s$ 为分母，$n$ 以 $V$ 为分母，分子都是 $V_v$，切勿混淆分母。

### 公式 1-5　饱和度

$$S_r=\frac{V_w}{V_v}\times100\%$$

- **参数说明**：$S_r$ 为饱和度（%），反映孔隙被水充满的程度。$S_r=100\%$ 即饱和土；$S_r=0$ 即干土。
- **工程分类参考**：稍湿 $S_r<50\%$，很湿 $50\sim80\%$，饱和 $>80\%$。

### 公式 1-6　干密度与干重度

$$\rho_d=\frac{m_s}{V},\qquad \gamma_d=\rho_d g$$

- **参数说明**：$\rho_d$ 为干密度；$\gamma_d$ 为干重度（$\mathrm{kN/m^3}$）。烘干后土的质量与总体积之比。
- **用途**：填土压实质量控制以 $\rho_d$（或压实系数 $\lambda_c=\rho_d/\rho_{d,\max}$）为标准。

### 公式 1-7　饱和密度与浮密度（有效重度）

$$\rho_{sat}=\frac{m_s+V_v\rho_w}{V}=\frac{m_s+V_v}{V}\,\mathrm{(g/cm^3)}$$

$$\rho'=\frac{m_s-\rho_w V_s}{V}\approx\rho_{sat}-\rho_w,\qquad \gamma'=\gamma_{sat}-\gamma_w$$

- **参数说明**：$\rho_{sat}$ 为饱和密度；$\rho'$ 为浮密度（水中单位体积土所受浮力折减后的等效密度）；$\gamma'$ 为浮重度（有效重度）。$\gamma_{sat}=\rho_{sat}g$。
- **单位**：$\rho$ 用 $\mathrm{g/cm^3}$，$\gamma$ 用 $\mathrm{kN/m^3}$。
- **注意**：**水下自重应力计算必须用 $\gamma'$；$\gamma'=\gamma_{sat}-\gamma_w$** 是最常用的换算关系（浮力原理），推导时用阿基米德浮力：土粒体积 $V_s$ 排开水重 $\rho_w V_s g$。

## 1.3 三相比例指标的互相换算（考点核心）

令 $\rho_w=1\,\mathrm{g/cm^3}$，设一个代表性三相图（以 $V_s=1$ 或 $m_s=1$ 为基准即可推出全部关系）。**掌握以下换算组**，考试任一已知组合均可求解：

### 公式 1-8　已知 $\rho,\omega,d_s$ → 求全部

$$e=\frac{d_s(1+\omega)\rho_w}{\rho}-1=\frac{d_s(1+\omega)}{\rho}-1\quad(\rho_w=1)$$

$$n=\frac{e}{1+e},\qquad S_r=\frac{\omega d_s}{e},\qquad \rho_d=\frac{\rho}{1+\omega}$$

- **推导骨架**（以 $m_s=1$ 为基准）：令 $m_s=1$，则 $m_w=\omega$，$V_s=\dfrac{1}{d_s}$（因 $d_s=\dfrac{m_s}{V_s\rho_w}=\dfrac{1}{V_s}$），$V_w=\omega$，$m=1+\omega$，$V=\dfrac{m}{\rho}=\dfrac{1+\omega}{\rho}$；于是 $V_v=V-V_s$，由 $e=\dfrac{V_v}{V_s}$、$n=\dfrac{V_v}{V}$、$S_r=\dfrac{V_w}{V_v}$ 逐项化简即得上式。
- **单位**：$\rho$ 用 $\mathrm{g/cm^3}$ 时与 $\rho_w=1$ 直接相除；若 $\rho$ 给的是 $\mathrm{kN/m^3}$ 需先换回。
- **注意**：这是**唯一必须记住的推导链**——考场上一旦忘公式，用「$m_s=1$ 基准法」30 秒内可全推出来。

### 公式 1-9　饱和度-孔隙比-含水率关系（常用总式）

$$\boxed{S_r=\frac{\omega d_s}{e}}$$

$\omega,\ d_s,\ e,\ S_r$ 四者知三求一。特别地，**饱和土（$S_r=1$）**时：

$$e=\omega_{sat} d_s,\qquad \omega_{sat}=\frac{e}{d_s}=\frac{n}{d_s(1-n)}$$

### 公式 1-10　密度/干密度/孔隙比互转

$$\rho=\rho_d(1+\omega)$$

$$\rho_d=\frac{d_s}{1+e}\quad(\rho_w=1),\qquad \rho=\frac{d_s(1+\omega)}{1+e}$$

$$\gamma=\frac{d_s(1+\omega)}{1+e}\gamma_w,\qquad \gamma_d=\frac{d_s}{1+e}\gamma_w$$

- **参数说明**：各符号同上；乘以 $\gamma_w$ 即得对应重度单位 $\mathrm{kN/m^3}$。
- **注意**：计算时务必统一 $d_s$（无量纲）与 $\rho_w=1\ \mathrm{g/cm^3}$；若直接代 $\gamma$ 表达式则 $\gamma_w=10\ \mathrm{kN/m^3}$。

### 公式 1-11　饱和密度/浮密度的另一种表达式

$$\rho_{sat}=\frac{d_s+e}{1+e},\qquad \rho'=\frac{d_s-1}{1+e}$$

$$\gamma_{sat}=\frac{d_s+e}{1+e}\gamma_w,\qquad \gamma'=\frac{d_s-1}{1+e}\gamma_w$$

- **推导要点**：令 $V_s=1$，则 $V_v=e$，$V=1+e$，$m_s=d_s$，恰好可验。显然 $\rho'=\rho_{sat}-\rho_w$ 与公式 1-7 一致。
- **注意**：此组公式将「重度计算」压缩为仅依赖 $d_s,e$，考试粒子题（给 $d_s,e$ 求 $\gamma,\gamma_d,\gamma_{sat},\gamma'$）直接用。

### 公式 1-12　用密度直接求浮重度

$$\gamma'=\gamma_{sat}-\gamma_w$$

- **注意**：地下水位以下土层若给的是**湿密度**，一般按**饱和处理**（水位以下地基土通常 $S_r=100\%$），即令 $\rho=\rho_{sat}$ 后用上式；若题目明示非饱和，按「水中自重 = 总重 − 浮力」逐分步计算（浮力 = $V_s\gamma_w$）。

## 1.4 黏性土的物理状态指标

### 公式 1-13　界限含水率与稠度

$$\omega_L\ \text{（液限）：} \ \text{流动}\leftrightarrow\text{可塑}$$
$$\omega_P\ \text{（塑限）：} \ \text{可塑}\leftrightarrow\text{半固态}$$
$$\omega_S\ \text{（缩限）：} \ \text{半固态}\leftrightarrow\text{固态}$$

### 公式 1-14　塑性指数

$$\boxed{I_p=\omega_L-\omega_P}$$

- **参数说明**：$I_p$ 为塑性指数（直接以百分数数值表示，不带 % 号），数值越大，黏粒含量越高、可塑范围越宽。
- **工程分类**：粉土 $I_p\le10$；黏性土 $I_p>10$（其中黏土 $I_p>17$，粉质黏土 $10<I_p\le17$）。
- **注意**：塑性指数各教材取下限临界值方式不同（有的取 $I_p>17$ 为黏土），以本校教材为准。

### 公式 1-15　液性指数与稠度状态

$$I_L=\frac{\omega-\omega_P}{I_p}=\frac{\omega-\omega_P}{\omega_L-\omega_P}$$

| $I_L$ 范围 | 稠度状态 | 力学行为 |
|-----------|---------|---------|
| $I_L\le0$ | 坚硬（固态） | 强度高 |
| $0<I_L\le0.25$ | 硬塑 | — |
| $0.25<I_L\le0.75$ | 可塑 | 一般地基/填土控制 |
| $0.75<I_L\le1.0$ | 软塑 | — |
| $I_L>1$ | 流塑 | 强度低，需处理 |

- **注意点**：$I_L$ 描述**天然状态**黏性土的软硬，$I_p$ 描述**可塑范围**，一个是状态量、一个是材料属性，勿混。

## 1.5 无黏性土的密实度

### 公式 1-16　相对密实度

$$D_r=\frac{e_{max}-e}{e_{max}-e_{min}}$$

- **参数说明**：$e_{max}$、$e_{min}$ 为最大、最小孔隙比（试验测出）；$e$ 为天然孔隙比。$D_r=0\sim1$。
- **分级**：松散 $0<D_r\le1/3$；中密 $1/3<D_r\le2/3$；密实 $2/3<D_r\le1$。
- **注意**：只适用于**无黏性土**；砂土也可用标准贯入锤击数 $N$ 判别（$N>30$ 密实，$10<N\le30$ 中密，$N\le10$ 松散）。

### 公式 1-17　颗粒级配评价指标

$$C_u=\frac{d_{60}}{d_{10}},\qquad C_c=\frac{d_{30}^{\,2}}{d_{60}\,d_{10}}$$

- **参数说明**：$d_{60},d_{30},d_{10}$ 为累计含量达 $60\%、30\%、10\%$ 时对应的粒径（mm），$d_{10}$ 又称有效粒径；$C_u$ 为不均匀系数，$C_c$ 为曲率系数。
- **判别**：级配良好需 **$C_u\ge5$ 且 $C_c=1\sim3$** 同时满足（粗粒土）。
- **工程意义**：$C_u$ 越大级配越良好、易于压实；$C_u$ 过小的均粒土不密实。
- > **双义警示**：$C_c$ 在此是**曲率系数**（级配），而在第四章 e-lgp 压缩曲线中另作**压缩指数**——两处含义不同，跨章复习注意区分；$C_u$（不均匀系数）与第五章 $c_u$（不排水抗剪强度）也仅大小写之别，阅读时看清下标。

## 1.6 土的工程分类（速记）

### 大类划分（按粒径组成）

| 大类 | 粒组组成（mm） | 特征 |
|------|--------------|------|
| 碎石土 | 粒径 $>2\,\mathrm{mm}$ 含量 $>50\%$ | 由碎石/角砾组成 |
| 砂土 | $>2\,\mathrm{mm}$ 含量 $\le50\%$，$>0.075\,\mathrm{mm}$ 含量 $>50\%$ | 砾砂/粗砂/中砂/细砂/粉砂 |
| 粉土 | $>0.075\,\mathrm{mm}$ 含量 $\le50\%$，塑性指数 $I_p\le10$ | 介于砂土与黏性土之间 |
| 黏性土 | $I_p>10$ | 粉质黏土 $10<I_p\le17$，黏土 $I_p>17$ |

### 黏性土的判别要点

- **用 $I_p$ 分类，用 $I_L$ 判状态**——两类指标分工不同。
- 判别流程：先判断是否粉土（按粒径与 $I_p$），再按 $I_p$ 细分黏性土。
